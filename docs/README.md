## Ruta de aprendizaje para los estudiantes

1. Ejecute la aplicación siguiendo el README principal.
2. Estudie las guías **01 y 02** para comprender el código y la base de datos.
3. Registre un préstamo de prueba y analice las reglas de negocio en la **guía 03**.
4. Trabaje las consultas de A7, A8 y A9 mediante la **guía 04**.
5. Abra el modo didáctico y consulte la **guía 05** para relacionar SQL y Java.
6. Complete las comprobaciones de la **guía 06**.

## Historial y vigencia

Los documentos anteriores se retiraron de `main` porque explicaban funcionalidades ya sustituidas: menús de versiones antiguas, laboratorios con 7 o 21 consultas y categorías/editoriales sin normalizar.

**No se pierde su contenido histórico**: permanece disponible mediante los commits y etiquetas de Git. Consulte [HISTORIAL.md](../HISTORIAL.md) y las [versiones conservadas](https://github.com/jgdiaz19/biblioteca-sql-java/tags).

Las guías describen un **proyecto didáctico**, no un software listo para uso público con datos personales.
