# Interfaz de consola

La aplicación limpia la pantalla al entrar y salir de los menús. Cada resultado permanece visible hasta pulsar ENTER. Se utiliza ANSI cuando la terminal lo admite; `FORCE_ANSI=true` lo activa y `NO_COLOR=1` deshabilita los colores.

- Azul UV: `#18529D`.
- Verde UV: `#28AD56`.
- Blanco para texto; fondo azul muy oscuro como elección de contraste para consola.

Las tonalidades institucionales se tomaron del documento de identidad de la UV. El splash contiene un monograma de caracteres «UV», **no una reproducción oficial del logosímbolo o escudo**. La terminal debe usar codificación UTF-8 y, preferentemente, una fuente monoespaciada.

En esta versión se solicita ENTER en lugar de cualquier tecla para que la entrada funcione con el lector de consola existente, sin alterar el modo del terminal.

Referencia de colores: https://lumen.uv.mx/resources/files/documents/2020/1/14/2877/b3379d1c-b003-4389-a03b-d939bd1813fe.pdf
